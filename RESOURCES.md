# Frontend engineering Resources

Lessons draw claims from these sources and cite them inline. Add a source here before a lesson relies on it.

## Knowledge

- [MDN Web Docs: Learn web development](https://developer.mozilla.org/en-US/docs/Learn_web_development)
  Mozilla's beginner curriculum, the reference standard for HTML, CSS and JavaScript. Use for: nearly every claim in Levels 1 to 6.
- [MDN: How the web works](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Web_standards/How_the_web_works)
  Clients, servers, DNS, TCP/IP and HTTP in plain language. Use for: Level 1 lessons 1 to 3.
- [MDN: What is a web server?](https://developer.mozilla.org/en-US/docs/Learn_web_development/Howto/Web_mechanics/What_is_a_web_server)
  Hardware and software sides of a server, how it answers requests, static vs dynamic, why hosting is always on. Use for: Level 1 lessons 1 and 6.
- [MDN: How browsers load websites](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Web_standards/How_browsers_load_websites)
  Opening a page sends several requests; the HTML triggers requests for CSS, JavaScript and media. Use for: Level 1 lessons 1 and 5.
- [Wikipedia: Data center](https://en.wikipedia.org/wiki/Data_center)
  What a data centre is: servers in racks, backup power, cooling, network connections. Use for: Level 1 lesson 1 (where servers live).
- [MDN: An overview of HTTP](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Overview)
  Requests, responses, methods, headers. Use for: Level 1 lesson 2.
