<Note term="Client">The computer that asks for a web page. On your phone or laptop, the browser does the asking.</Note>

Every time you open a web page, two computers work together. One computer asks for the page. The other computer has the page and sends it. The one that asks is called the client. The one that sends is called the server.<Cite n={1} />

<Note term="Browser">The app you use to look at web pages. Chrome, Safari and Firefox are browsers.</Note>

Your phone, tablet or laptop is a client. To look at web pages, you use an app called a browser, such as Chrome, Safari or Firefox. When you open a page, your browser is the one doing the asking.

<Note term="Server">A computer that keeps a website’s files and sends copies to anyone who asks.</Note>

A server is a computer that keeps a website’s files.<Cite n={2} /> A website is made of files, the same way your phone is full of photos and documents. Some files hold the words and the layout of the page. They are written in code called HTML, CSS and JavaScript. Other files are pictures and fonts. When a client asks, the server sends copies of those files.

## One trip, start to finish

Opening a page happens in three steps:

1. Your browser asks the server for the page.
2. The server finds the files for that page.
3. The server sends copies of the files back, and your browser puts them together into the page you see.

The asking has a name: a request. The answer has a name too: a response. Section 1.2 is all about those two.

The server keeps its own files. It only ever sends copies, so it still has the page for the next person who asks. A busy server answers lots of clients at the same time, the way one kitchen cooks for a whole restaurant.

## How a server finds a file

<Note term="404 Not Found">The error a server sends back when it does not have the file you asked for.</Note>

Every request asks for one file by its name. The server looks for a file with that name. If it has the file, it sends a copy. If it does not have it, it still answers, but the answer is an error that says the file was not found. That error is called 404 Not Found.<Cite n={2} />

</Figure>

## Worth knowing

- A server is a normal computer. Most servers have no screen. They stay switched on day and night, so they can answer whenever someone asks.<Cite n={2} />
- A server and a website are not the same thing. The website is the files. The server is the computer that keeps them, and one server can keep many websites.<Cite n={2} />
- Client and server are jobs, not special kinds of computer. Later in this course you will turn your own laptop into a small server, and the browser on that same laptop will be its client.
