You typed an address or tapped a link, and this page appeared. In the moment between, your device asked another computer for the page, and that computer sent it back. Your browser kept a record of the trip:

<ThisPage />

<Note term="Client">The device that asks for a web page, together with the program on it doing the asking.</Note>

The computer at that address is a server. Your device, with the browser on it, is the client.<Cite n={1} /> Every page on the web reaches you this way.

<Note term="Browser">The app you use to open web pages.</Note>

A client is your phone, laptop or tablet, plus the program on it that does the asking. Most of the time that program is a browser, such as Chrome, Safari or Firefox.

<Note term="Server">A computer that stores a website’s files and sends copies to the clients that ask.</Note>

A server is a computer that stores a website’s files and sends a copy to any client that asks for them.<Cite n={2} /> Those files are the website itself: code written in HTML, CSS and JavaScript, plus things like images and fonts.

The server keeps its files after it answers, because it only ever sends copies. That is how the next client gets the same page. A busy server answers many clients at the same time, the way one kitchen cooks for a full restaurant.

## How a server finds a file

<Note term="404 Not Found">The answer a server gives when it has no file for the address it was asked for.</Note>

Each request names the file the client wants. The server checks whether it has a file by that name. If it does, it sends a copy back. If it does not, it still answers, with an error message. The most common one is 404 Not Found.<Cite n={2} />

## Worth knowing

- Most servers have no screen and stay switched on all day, so they can answer at any hour.<Cite n={2} />
- Client and server are jobs, not kinds of machine. Later in this course you will run a small server on your own laptop, and the browser on that same laptop will be its client.

<MixUp>
A server and a website are different things. The website is the files. The server is the computer that holds them and hands out copies, and one server can hold many websites.<Cite n={2} />
</MixUp>

<InShort>
- The client asks for a page, and most of the time the client is your browser.
- The server stores a website’s files and sends copies to any client that asks.
- Every request names a file. If the server has no such file, it answers 404 Not Found.
</InShort>
