# Mission: Frontend engineering from zero

## Why
Take someone who has never written code to the point where they can get hired as a frontend engineering intern, and then keep growing toward senior. Every lesson should move a learner closer to doing real frontend work, not just knowing words.

## Success looks like
- Explain what happens between typing a URL and seeing a page, in plain words
- Build and style responsive, accessible pages with HTML and CSS
- Write JavaScript that responds to users and talks to APIs
- Build a small app with a component framework, with state, routing and data fetching
- Pass a frontend intern interview: core concepts, live coding, a small system design question
- Later levels: reason about performance, security, testing and architecture like a senior

## Constraints
- Learners start with zero programming knowledge. Define every new word the first time it appears.
- Lead every new idea with a real-life comparison before the technical term.
- Lessons are short: one idea, one win, finishable in one sitting.
- Built one level and one lesson at a time, each reviewed before the next.

## Out of scope
- Backend engineering beyond what a frontend engineer needs to talk to an API
- Mobile app development
- Specific framework deep dives before Level 8
