# Working notes

- Course name: FrontendEngineerIntern.
- The course reads as a typographic book: levels are chapters, lessons are numbered section pages (1.1, 1.2), with a contents page, chapter openers, numbered figures with captions, margin notes and footnote-style sources. Exercises close each section.
- Short and direct; treat every learner as an absolute beginner. No analogy boxes: an analogy only appears in passing inside the text.
- All copy goes through the humanizer skill. No em dashes.
- A section can carry several anatomy figures, each a working machine for one part of the idea. Figures are the only imagery in the course.
- Build order: landing page, Level 1 overview, then one lesson at a time with review between.
- Quiz answers have the same number of words so formatting never gives the answer away.
- Every lesson ends with a reminder that learners can ask follow-up questions.
